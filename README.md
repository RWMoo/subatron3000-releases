# Subatron 3000 - releases

Installers and update files for Subatron 3000. Installed copies check here for updates by
themselves. There's no source code in this repository.

Download from the latest release under **Releases**:

- **Windows:** `Subatron-3000-Setup-<version>.exe`. Windows may say "Windows protected your PC"
  the first time: click **More info**, then **Run anyway**.
- **Linux (AppImage):** `Subatron-3000-<version>.AppImage` - `chmod +x` it and run it. Ubuntu
  22.04+ needs `sudo apt install libfuse2t64` (or `libfuse2` before 24.04).
- **Linux (.deb):** `sudo apt install ./Subatron-3000-<version>.deb`. Updates ask for your
  password to install.
