# Subatron 3000 - releases

Installers and update files for Subatron 3000. The app checks here for updates by itself.

To install, download `Subatron-3000-Setup-<version>.exe` from the latest release under
**Releases**. Windows may say "Windows protected your PC" the first time: click **More info**,
then **Run anyway**.

There's no source code in this repository.
